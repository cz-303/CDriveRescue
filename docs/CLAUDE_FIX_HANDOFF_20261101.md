## 1. 修复已有硬链接仍被重复计数

**位置：** `src/core/disk_analyzer.py` → `scan_duplicate_files_fast()`。

**上次证据：** 当前 Windows 环境中，`DirEntry.stat().st_ino` 返回 0，而 `os.stat()` 可以得到真实文件标识。创建三个各 4096 字节的文件，其中 a、b 已为同一实体的硬链接，c 是独立的相同内容文件；扫描仍报告两个副本、可省 8192 字节，实际只可再消除一个独立副本。

**修改要求：**

- 使用可靠的 `(st_dev, st_ino)` 文件身份；无法可靠识别时保守处理。
- 按卷组织可硬链接合并的候选组，避免跨卷选择主文件而漏掉同卷可合并的文件。
- 对组内全部实体去重，不能只将每个副本与第一个主文件比较。
- 去除重复扫描根及嵌套扫描根导致的重复路径。
- 与执行器保持一致：它拒绝合并已有多个链接的副本。优先保留已共享实体作为主文件，不应把执行器必然拒绝的副本计入可省空间。

**验收：** 修复 `tests/test_gemini_foundation.py` 中 `test_v11_hardlink_validation_and_duplicate_scanner` 的现有失败；补充已有硬链接、重叠扫描根、多卷和重复执行后的统计用例。上述 a/b/c 示例应只计一个可合并副本。

## 2. 读取 Windows 真实个人文件夹位置

**位置：** `src/core/disk_analyzer.py` → `inspect_windows_known_folders()`；重复附件默认扫描目录；`src/ui/lab_page.py` 的 `_default_dup_roots()`。

**上次发现：** 扫描器按用户主目录拼接 Downloads/Desktop/Documents 等默认名称。用户改过位置、使用 OneDrive 或刚通过本工具迁移后，扫描仍显示旧路径。`SystemOptimizer._folder_paths()` 会核对 Windows 真实路径，因此会拒绝这种过期条目；反复扫描也不能解决。

**修改要求：**

- 正常 Windows 运行时，通过 `SHGetKnownFolderPath` 获取五类个人文件夹实际位置。
- 保留显式 `custom_user_home` 测试/自定义模式，避免破坏现有测试接口。
- 获取路径失败时明确返回错误或不可操作状态，不把猜测路径当成已确认路径。
- 系统盘判断使用实际系统盘，不写死 C。
- 重复附件的默认 Documents/Downloads 根目录也从真实位置派生。
- 保留执行器对 OneDrive 管理范围、重解析点、过期路径及目标冲突的防护。

**验收：** 模拟已重定向至 D 盘的 Downloads、OneDrive 路径、API 失败及迁移后再次扫描；确认路径、体积及系统盘标记正确。测试不得修改用户真实 Known Folder 配置。

## 3. 修复个人文件夹迁移成功后不刷新

**位置：** `src/ui/lab_page.py` → `KnownFoldersPanel._on_moved()`、`scan()`、`move()`，以及 `_Panel._run()` 的结束回调。

**上次发现：** `_on_moved()` 在 succeeded 回调中直接调用 `scan()`，而线程仍在 `_threads` 中，`busy` 为 True，刷新立即返回。finished 回调随后只释放闸门和恢复按钮，没有重新检测。此前已模拟这两个方法确认该路径，尚未完成真实 Qt 验证。

**修改要求：** 在线程从列表移除、写操作闸门释放后触发刷新；或先用返回的 `KnownFolderItem` 更新卡片，再在结束后重新检测。确保成功、失败、恢复事务及清理备份产生警告时，界面状态均正确。

**验收：** 补充离屏 UI 测试，断言迁移后卡片显示新路径及正确按钮状态，而不只是断言后端被调用。确认无重复刷新、卡死或线程提前销毁。

## 4. 缺少进程检测依赖时禁止回收残留目录

**位置：** `src/ui/workers.py` → `recycle_orphan_dir()`、`inspect_orphan_dir()`；残留回收确认界面。

**上次发现：** `recycle_orphan_dir()` 仅在能够找到 psutil 时进行占用检查，缺少依赖仍会调用 Send2Trash。界面虽提示无法检查，但仍允许继续，与旧迁移“无法检查则拒绝”的策略不一致。

**修改要求：** 真正回收前无条件通过 guard 的占用检查；缺少依赖或检测失败时停止写操作并解释原因。只读扫描可以继续。缺少 Send2Trash 时也不得退回永久删除。

**验收：** 对缺少 psutil、占用检测异常、检测到占用三种情况，断言 `send2trash` 均未被调用。回收测试使用替身，不处理真实用户目录。
