## CDriveRescue v1.1.0 · 深水区瘦身实验室

在 v1.0 的体检、缓存清理、大文件猎手、软件搬家之上，新增四项更深入的 C 盘瘦身功能。

### 下载与运行
1. 下载下方的 `CDriveRescue-v1.1.0-win64.zip`。
2. **解压整个文件夹**，运行其中的 `CDriveRescue.exe`（只拿 exe 无法运行）。
3. 未签名程序，首次运行若出现“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。

支持 Windows 10 / 11 64 位，无需安装 Python。从 v1.0 升级：直接用新文件夹替换旧文件夹即可，迁移记录保存在用户目录下的 `.cdriverescue`，不受影响。

### 新功能
- **重复附件硬链接合并**：内容完全相同的微信 / QQ 附件只保留一份数据，每个文件仍在原位置、原文件名。合并后这些路径共享同一份数据，以后修改其中一个，其他也会一起变，只适合收到后不再修改的附件。数据库、配置、日志类文件自动排除，可先预演。
- **个人文件夹搬家**：用 Windows 自己的接口把下载、桌面、文档、视频、图片改到其他盘；位置从 Windows 实际读取，先复制并逐个校验再改绑，中断后可恢复。OneDrive 管理的文件夹不处理。
- **卸载残留猎手**：列出疑似已卸载软件留下的 AppData / ProgramData 文件夹，逐个复核后移入回收站；无法检查是否有程序占用时不处理。
- **Windows 组件存储清理**（C 盘体检页）：调用 Windows 自带的 DISM 组件清理，需要管理员权限；不使用 `/ResetBase`，不自动重启。

### 改进与修复
- 重复文件扫描按真实文件身份识别已有硬链接，不再重复计算可省空间；多盘、重叠扫描目录都能正确处理。
- EXE 内嵌版本信息；打包流程会自动核对产物。

### 已验证
- Windows 11 上 123 项自动化测试全部运行并通过（含真实 NTFS 硬链接、联接与跨卷迁移）
- 打包产物内容核对，实机启动验收
- 文件操作只在测试文件夹上实测；个人文件夹改绑、DISM 清理在测试中为模拟

### 已知限制
- 硬链接合并后的文件共享后续修改；多步文件操作不是断电级原子事务，请先备份重要数据
- 组件清理可能耗时 10 分钟以上，释放的空间取决于系统更新情况，可能很少
- 卸载残留的判断依据名称和修改时间，可能误判；移入回收站后可还原
- 程序未签名，个别杀毒软件可能误报
