## CDriveRescue v1.0.0 · 首个版本

Windows 桌面工具：看清 C 盘为什么满、保守清理缓存、把大文件夹无损迁移到其他磁盘。

### 下载与运行
1. 下载下方的 `CDriveRescue-v1.0.0-win64.zip`。
2. **解压整个文件夹**，运行其中的 `CDriveRescue.exe`（只拿 exe 无法运行）。
3. 未签名程序，首次运行若出现“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。

支持 Windows 10 / 11 64 位，无需安装 Python。

### 功能
- **C 盘体检**：焦虑指数、容量概览、清理建议、可用目标磁盘、休眠文件/虚拟内存说明
- **缓存清理**：7 条保守规则（系统临时文件、Chrome / Edge / Firefox、pip / npm、旧版微信缓存）；默认移入回收站，支持预演；“谨慎”项默认不勾选
- **大文件猎手**：按阈值找出大文件，只定位不删除
- **软件搬家**：复制 → SHA-256 逐文件校验 → 切换为目录联接；失败自动回滚，中断可恢复
- **迁移记录**：联接状态检查、一键还原（目标盘副本保留）

### 已知限制
- 未逐个验证真实软件迁移后的启动、更新与卸载；请只迁移你了解的普通软件或数据目录
- 移入回收站不会立即释放空间，需清空回收站
- “扫描大文件夹”需要检查进程占用，可能耗时几分钟
- 程序未签名，个别杀毒软件可能误报
